# ADR-V-0014: Decorator Inference Agent (Self-Healing Graph)

**Status:** proposed  
**Created:** 2024-03-10  
**Authors:** adr-architecture-kit  
**Domains:**   
**Tags:** decorator-inference, self-healing-graph, ai-agent, graph-completion, autonomous-systems  




---

## Context

The semantic graph is incomplete without explicit ADR-to-code edges:
- ADR slices exist (extracted from YAML files)
- Code slices exist (extracted from source code)
- Edges between them? Missing (no decorators)

Problems with incomplete graph:
- Can't query "what code implements this ADR?" (no edges to traverse)
- Can't validate code matches spec (no links to compare)
- Can't detect drift (no way to know what changed)
- Can't do surgical review (can't isolate relevant code)
- Can't measure compliance (can't find code to check)

Manual decoration is broken:
- Developers forget decorators (human error)
- Manual decoration is tedious (low adoption)
- No feedback loop (graph stays broken)

Opportunity: Self-healing graph through confident targeted reasoning.

## The Self-Healing Paradigm

Traditional graphs:
- Static structure (edges defined manually)
- Incomplete by default (humans forget to link)
- No self-awareness (can't detect missing edges)
- No self-repair (requires manual fixes)

Self-healing semantic graph:
- Dynamic structure (edges inferred automatically)
- Complete by default (AI fills gaps)
- Self-aware (detects incomplete edges)
- Self-repairing (reasons and heals autonomously)

The graph reasons over its own structure to complete itself.
