## What ADR Kit Is

Consume supported programmatic behavior through adr_kit.api, treat accepted authored artifacts as canonical intent for their scope, and treat normalized models and generated artifacts as derived semantic surfaces rather than independent authority.

ADR Kit is STE's authoring-side provider for structured architectural intent and deterministic authoring operations. This overview orients AI-first contributors to supported surfaces; it is generated and not normative authority.

It provides:

- Validate, compile, query, migrate, and promote through supported provider operations
- Keep accepted project ADRs as canonical project intent for their declared scope
- Keep ste-spec as normative cross-repository semantic contracts where assigned
- Keep ste-runtime as runtime extraction, factual evidence, and derived runtime state

Implementation embodies accepted authority; it does not silently redefine it. Authority is responsibility-scoped, not a single global precedence chain.
