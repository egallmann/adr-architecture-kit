# ADR-V-0004: Bidirectional Translation Layer

**Status:** proposed  
**Created:** 2024-03-10  
**Authors:** adr-architecture-kit  
**Domains:**   
**Tags:** translation, human-ai-interface, schema, prompts  




---

## Context

Humans and AI speak different languages:
- Humans: Natural language (conversational, ambiguous, contextual)
- AI: Structured data (JSON, YAML, precise, formal)

Traditional approach: Force humans to learn AI's language
- Write YAML/JSON manually
- Learn schema rules
- Understand validation errors

Problems:
- High friction (humans must learn syntax)
- Error-prone (syntax errors, schema violations)
- Inaccessible (technical knowledge required)
- Slow (manual typing, formatting)

Opportunity: Let AI translate between human and machine language.

The ADR schema is already a translation layer:
- Converts human intent → structured data
- But humans still see the structure (YAML editing)

Vision: Humans never see structure, only conversation.
