# ADR-V-0007: Compliance AI Agent

**Status:** proposed

## Context

Compliance violations are detected by Autonomous Compliance System (ADR-L-0006).

Current state: Violations flagged, humans fix manually
- Compliance report shows violations
- Developers read report
- Developers implement fixes
- Developers test fixes
- Developers submit for review

Problems:
- Slow (developers have other priorities)
- Error-prone (humans make mistakes)
- Inconsistent (different developers fix differently)
- Expensive (developer time costly)

Opportunity: AI can propose and implement fixes automatically.

The system has complete context:
- ADR (what system should be)
- EDR (what system actually is)
- Policies (what standards to follow)
- Violation (what's wrong)

AI can reason over this context and generate compliant fixes.
