# Phase 1 narrow public SDK decision journal

Status: authority review ready  
Authority baseline: `27b041da093a2e95ee8698be3ac2211156caad8e`

## Problem and authority boundary

Phase 0 established release, compatibility, reproducibility, governance, and
quality controls, but the package still lacks a deliberately supported authoring
SDK. New consumers otherwise have to choose between the stable repository/model
seam and compiler internals whose result graph contains `ArchModel`, mutable
artifacts, and a mutable diagnostic log.

Canonical ADRs remain authority. Generated projections and runtime graph state are
derived and are never edited as authority. Phase 1 may add an authoring-side facade,
but it may not change ADR schema v1.0, expand `NormalizedArchitectureModel`, change
CLI behavior or generated bytes, expose compiler internals, or introduce graph,
Architecture IR, recursive-workspace, runtime-evidence, rules, substrate, admission,
Assembler, MCP, or LLM capabilities.

## Alternatives and decisions

| Concern | Alternatives considered | Phase 1 decision |
| --- | --- | --- |
| Public location | Root re-exports, broaden existing modules, dedicated module | Add `adr_kit.api`; keep the package root version-only. |
| API shape | Stateful service, functions | Use four functions; no public lifecycle is needed. |
| Compiler result | Reuse, subclass, wrap | Introduce an independent immutable public result. |
| Repository | Replace, wrap, reuse | Return the existing `ArchitectureRepository`. |
| Normalized model | New DTO, expand, reuse | Re-export the existing model unchanged and return detached instances. |
| Artifacts | Paths, bytes, bounded descriptor | Use immutable descriptors with identity, bytes, hashes, and optional written paths. |
| Compilation breadth | All compiler features, stable authoring subset | Support only `registries`, `manifest`, and `markdown` for one explicit scope. |
| Diagnostics | Compiler types, public value contract | Use an immutable diagnostic with literal string severity. |
| Version authority | Duplicate literal, generated file, metadata-first | `pyproject.toml` is the only edited version; installed metadata is primary with a bounded source fallback. |
| Deprecation | Warn on historical imports, preserve | Preserve without warnings in Phase 1. |

## Exact supported inventory

`adr_kit.api.__all__` is exactly:

```python
[
    "ArchitectureRepository",
    "NormalizedArchitectureModel",
    "ArtifactDescriptor",
    "CapabilityManifest",
    "ValidationRequest",
    "ValidationResult",
    "CompilationRequest",
    "CompilationResult",
    "Diagnostic",
    "SDKError",
    "InvalidRequestError",
    "OperationError",
    "RepositoryError",
    "capabilities",
    "validate_architecture",
    "compile_architecture",
    "open_repository",
]
```

The supported operations are:

```python
def capabilities() -> CapabilityManifest: ...
def validate_architecture(request: ValidationRequest) -> ValidationResult: ...
def compile_architecture(request: CompilationRequest) -> CompilationResult: ...
def open_repository(project_root: str | Path) -> ArchitectureRepository: ...
```

`capabilities()` is deterministic and local. It reads installed metadata and
bundled resources only. Validation and compilation operate on one explicit project
root. `open_repository()` resolves the root and eagerly returns
`ArchitectureRepository(resolved_root).load()`.

## Request contracts

All request types are frozen, slotted dataclasses and normalize at construction.

```python
@dataclass(frozen=True, slots=True)
class ValidationRequest:
    project_root: Path
    mode: Literal["complete", "structural"] = "complete"
    cross_references: bool = False

@dataclass(frozen=True, slots=True)
class CompilationRequest:
    project_root: Path
    artifact_groups: tuple[str, ...] = (
        "registries",
        "manifest",
        "markdown",
    )
    write: bool = False
    output_root: Path | None = None
    timestamp: str | None = None
```

The project root becomes absolute and must contain `PROJECT.yaml` and `adrs/`.
Validation modes are exactly `complete` and `structural`. Compilation groups are
exactly `registries`, `manifest`, and `markdown`; empty, duplicate, and unknown
sets are invalid, while accepted sets are reordered canonically. `output_root` is
invalid unless `write=True`; a write without it targets the project root. A supplied
output directory may be created by existing compiler behavior. A timestamp is
either `None` or RFC 3339 UTC ending in `Z`. Deterministic bytes are promised only
for identical inputs and an explicit identical timestamp.

## Result contracts

All new results and descriptors are frozen, slotted dataclasses. Public collections
are tuples.

```python
@dataclass(frozen=True, slots=True)
class ValidationResult:
    request: ValidationRequest
    success: bool
    validated_files: tuple[str, ...]
    diagnostics: tuple[Diagnostic, ...]
    error_count: int
    warning_count: int
    package_version: str
    api_contract_version: str

@dataclass(frozen=True, slots=True)
class ArtifactDescriptor:
    artifact_id: str
    group: str
    kind: str
    relative_path: str
    written_path: Path | None
    content: bytes
    size_bytes: int
    sha256: str
    integrity_header: str | None

@dataclass(frozen=True, slots=True)
class CompilationResult:
    request: CompilationRequest
    success: bool
    partial: bool
    artifacts: tuple[ArtifactDescriptor, ...]
    diagnostics: tuple[Diagnostic, ...]
    model: NormalizedArchitectureModel | None
    fingerprint: str | None
    source_files: int
    parse_errors: int
    entities_extracted: int
    relationships_derived: int
    unresolved_detected: int
    artifacts_emitted: int
    package_version: str
    api_contract_version: str
```

Validation processes all discovered files. Errors produce `success=False`, warnings
do not. Schema, semantic, and malformed-file failures are completed results rather
than exceptions; an I/O or application failure preventing completion raises
`OperationError`.

Preview compilation returns artifact bytes with no written paths and performs no
writes. Equivalent write compilation returns the same bytes and absolute resolved
written paths. Failure after emission is unsuccessful and partial while retaining
available descriptors and model; failure before emission is unsuccessful,
non-partial, and has no artifacts, model, or fingerprint. Invalid requests raise
`InvalidRequestError` before compiler invocation. Unexpected compiler or I/O errors
raise a chained `OperationError`; writes remain explicitly non-transactional.

Artifact descriptors are sorted by POSIX-normalized `relative_path`. Their hashes
are lowercase SHA-256, `size_bytes == len(content)`, and integrity headers are
preserved without reinterpretation. Stable IDs are `manifest`,
`architecture-index`, `entity-registry`, `relationship-registry`,
`unresolved-registry`, `decision-registry`, `capability-registry`,
`invariant-registry`, `component-registry`, `system-registry`,
`legacy-entity-registry`, and `rendered-adr:<ADR-ID>`.

The model and fingerprint exist only when registry projection succeeds. The model is
detached from repositories, later operations, and compiler state. Its fingerprint
equals `ArchitectureRepository.fingerprint` for the equivalent written bundle.

## Diagnostic and error contracts

```python
@dataclass(frozen=True, slots=True)
class Diagnostic:
    severity: Literal["info", "warning", "error"]
    code: str
    message: str
    path: str | None = None
    source_ref: str | None = None
    field: str | None = None
```

Validator severity, rule, message, and field map directly; the validated ADR supplies
the path. Compiler level, code, message, path, and source reference map directly,
with `field=None`. Project-contained paths are project-relative POSIX strings and
unavoidable external paths are absolute POSIX strings. Validation is ordered by
path, errors before warnings, original order within each group, then cross-reference
diagnostics. Compilation preserves `DiagnosticLog.as_list()` ordering. Meaning and
message text do not change, and no compiler diagnostic object crosses the boundary.

The hierarchy is:

```text
SDKError
|- InvalidRequestError (also ValueError)
`- OperationError
   `- RepositoryError
```

`InvalidRequestError` covers invalid roots, modes, groups, timestamps, and
write/output combinations. `RepositoryError` wraps and chains
`ArchitectureRegistryError`. Expected validation/compiler diagnostics are results;
unexpected failures are chained exceptions. Exception wording is not stable.

```python
@dataclass(frozen=True, slots=True)
class CapabilityManifest:
    package_version: str
    api_contract_version: str
    operations: tuple[str, ...]
    validation_modes: tuple[str, ...]
    artifact_groups: tuple[str, ...]
    supported_adr_schema_versions: tuple[str, ...]
    stable_adr_schema_versions: tuple[str, ...]
    provisional_adr_schema_versions: tuple[str, ...]
    normalized_model_schema_version: str
```

Phase 1 values are API contract `1.0`; operations `capabilities`,
`validate_architecture`, `compile_architecture`, `open_repository`; validation modes
`complete`, `structural`; artifact groups `registries`, `manifest`, `markdown`;
supported ADR schemas `1.0`, `1.1`; stable schema `1.0`; provisional schema `1.1`;
and normalized-model schema `1.0`. `as_dict()` preserves field order and converts
tuples to JSON-safe lists. Tests cross-check schema claims against bundled resources.

## Internal containment and compatibility

The facade permits only primitives, `Path`, bytes, tuples, its own contracts,
`ArchitectureRepository`, and `NormalizedArchitectureModel`. It translates and
discards `ArchModel`, compiler configuration, compiler/pass/backend/frontend
objects, internal output artifacts, mutable diagnostic logs/lists, caches, and
emitters. Static annotations and recursive runtime object graphs prove containment.

The existing repository and normalized-model contracts remain unchanged. Historical
deep imports, including `adr_kit.compiler.CompilationResult`, remain callable and
compatibility-tested without warning. CLI `validate` and `compile` may delegate only
through private compatibility adapters that preserve every existing option, output
byte, diagnostic, exit code, and generated artifact byte. The pre-delegation
behavior snapshot is immutable evidence, not a baseline to refresh after drift.

## Version authority

`pyproject.toml:[project].version` is the sole manually edited version. Runtime
resolution first asks `importlib.metadata.version("adr-architecture-kit")`. Only
`PackageNotFoundError` permits a direct-source fallback to the repository
`pyproject.toml`, whose project name must match. If neither is valid, the explicit
non-release sentinel is `0+unknown`. The package root, CLI, capabilities, and SDK
results share this resolver. Editable and wheel installations must prove they use
distribution metadata. The feature remains `0.1.0`; `0.2.0` needs a separate
post-acceptance release decision.

## Authority review and lock criteria

The accepted logical ADRs authorize the facade, containment invariant, capability,
and metadata-first equivalence invariant. Proposed physical ADRs describe the
implementation boundaries without silently changing their status. Authority is
locked only after cross-reference validation, deterministic authoring projection
regeneration, a runtime-derived refresh, and a second zero-diff validation pass.

Production code remains blocked until that gate is green. Any required schema/model
expansion, public compiler-internal leakage, CLI or artifact drift, incompatible
runtime overwrite, dynamic capability claim, or weakening of Phase 0 controls stops
implementation and returns the contradiction to architecture authority.
