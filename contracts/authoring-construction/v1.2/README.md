# Authoring Construction Contract 1.2

This is an immutable authority publication implementing accepted ADR-L-0035
(DEC-0274–DEC-0279 and INV-0284–INV-0292). Canonical JSON resources govern;
this document is explanatory.

`contract.json` is generated by `scripts/generate_semantic_contract_assets.py`.
Its SCF includes the exact resource manifest and only
`authoring-construction/1.2/conformance` as frozen normative conformance.
The complete predecessor closure is retained by exact digest, including the
unchanged ACC 1.1 ledger schema and 40 unchanged schema definitions by exact
resource reference. Historical conformance is a dependency, not
ACC 1.2 runtime coverage.

The new closure members are `schema`, `rules`, `compatibility`, `conformance`,
`conformance.schema`, `composition-bindings`, and `composition-bindings.schema`
under `authoring-construction/1.2/`. The binding table has exactly one row:
`adr-logical.decisions.contains.entity-decision`. It selects the exact
Authoring 1.7 decision schema, ADC 1.1 composition/identity policies, and AI 1.2
ordered child-membership disposition. ADC `input_contract` does not define the
prepared decision-field inventory.

The ACC schema describes partitioned composition records and future complete
construction evidence. The request's ACC SCF must match the verified enclosing
definition. It is represented by the SCF wire shape plus an exact-match rule,
so the enclosing SCF is never embedded in its own closure. Table and companion
schema digests are included in the manifest, and the rules pin both digests.

Frozen cases ACC12-01–ACC12-41 are authority-only oracles. They cover prepared
containment, ordering, identity/field preservation, source-root accounting,
endpoint and ownership failures, authority faults, outcome precedence, and
retained diagnostics. Publication tests validate their shape and authority;
they do not execute a composition compiler or claim runtime conformance.

Python exact-version discovery and Node semantic-resource packaging expose
this definition through the existing shared Rust/WASM verification APIs.
Current semantic-contract selection and protocol 1.5 remain unchanged.
ACC 1.1 composition remains `Unavailable`, and protocol 1.5 retains
`composition_resolution: false`. No ACC 1.2 execution capability, composed
basis seal, `Constructed` result, binding, persistence, or promotion is enabled.

A separately authorized executable slice can qualify this exact table and
its endpoint binding with the specified fail-closed diagnostics. Compiler
insertion, complete detached NM 2.4 interpretation, ledgers, and equality
require their own subsequent implementation and qualification.
