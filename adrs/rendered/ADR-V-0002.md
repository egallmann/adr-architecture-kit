# ADR-V-0002: Agent Tier System

**Status:** proposed  
**Created:** 2024-03-10  
**Authors:** adr-architecture-kit  
**Domains:**   
**Tags:** ai-agents, cost-optimization, performance, democratization  




---

## Context

AI agent systems typically use a single model type (e.g., GPT-4) for all tasks.

Problems with single-model approach:
- Expensive: $0.03-0.10 per 1K tokens for foundation models
- Slow: 5-10 seconds per response (API latency)
- Wasteful: Using GPT-4 for simple tasks is overkill
- Centralized: Requires cloud API access, privacy concerns

Many tasks don't require foundation model capabilities:
- Rule-based validation (deterministic logic)
- Template filling (structured data)
- Code formatting (syntax rules)
- Coverage checks (count lines)

Opportunity: Match task complexity to model capability.
