# ADR-V-0008: Provider Ecosystem

**Status:** proposed  
**Created:** 2024-03-10  
**Authors:** adr-architecture-kit  
**Domains:**   
**Tags:** providers, marketplace, ecosystem, collaboration  




---

## Context

Specialized AI companies focus on specific domains:
- Security (StackHawk, Snyk, Checkmarx)
- Testing (Mabl, Testim)
- Code quality (Qodo, SonarQube)
- Observability (Datadog, New Relic)
- Performance (Sentry, AppDynamics)

These companies have deep expertise in their domains.

Current state: Each company builds custom integrations
- Custom API for each customer
- Custom report format
- Manual review process
- No standard for proposals

Problems:
- Integration burden (each customer different)
- Manual process (humans review proposals)
- No common language (each provider different format)
- Trust issues (how to verify provider identity/integrity)

Opportunity: Standardize provider proposals using ADR format.

This vision ADR is intentionally lightweight and does not yet formalize architectural decisions as `DEC-*` entries.
