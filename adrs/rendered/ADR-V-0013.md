# ADR-V-0013: Legacy Import Agent (Trust-First Validation)

**Status:** proposed  
**Created:** 2024-03-10  
**Authors:** adr-architecture-kit  
**Domains:**   
**Tags:** legacy-import, reverse-engineering, onboarding, trust-first  




---

## Context

Organizations have existing systems without ADRs:
- Legacy codebases (10+ years old)
- Undocumented architecture (tribal knowledge)
- No design records (decisions lost)
- Unknown invariants (implicit constraints)

Onboarding to ADR Kit requires documentation:
- Create ADRs for existing systems
- Extract design from code (reverse engineering)
- Validate with humans (confirm understanding)

Traditional approach: Manual documentation
- Developers read code
- Developers write ADRs
- Developers validate with experts
- Timeline: Weeks to months

Problems:
- Slow (manual process)
- Incomplete (developers miss details)
- Expensive (developer time)
- Tedious (developers hate documentation)

Opportunity: AI-driven reverse engineering with conversational validation.








## Vision Status

This vision ADR is intentionally lightweight and does not yet formalize architectural decisions as `DEC-*` entries.
